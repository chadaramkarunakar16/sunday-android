# Sunday for Android

The Android app for Sunday, my personal voice assistant. It shows the Sunday web app full screen and listens for "Hey Sunday" in the background, on the phone only.

**Download the latest APK:** https://github.com/chadaramkarunakar16/sunday-android/releases/latest/download/Sunday.apk

The app only works with its owner's sign-in. It contains no keys or personal data.
